🌾 Agro Market Management System (Java)
A comprehensive desktop application built to bridge the gap between farmers, suppliers, and buyers. This system digitizes the agricultural supply chain to ensure fair pricing and efficient inventory tracking.

Tech Stack: Java,GUI

Key Features:

Inventory Management: Track agricultural products, crop categories, and stock levels in real-time.

Marketplace Operations: Manage buying and selling transactions between registered farmers and vendors.

User Dashboards: Dedicated role-based access for Admins, Farmers, and Buyers to streamline the trading process.

Developed by Rejowan Al Shadid & Team | Computer Science & Engineering

🎓 University Management System (Java)
An integrated academic management system designed to handle the core administrative and academic operations of a university setting smoothly and efficiently.

Tech Stack: Java, JavaFX/Swing, SQL Database

Key Features:

Student Portal: Manage student enrollment, course registration, and grade tracking.

Faculty Management: Assign courses to teachers, manage schedules, and track employee details.

Administrative Control: Oversee department data, financial fee collections, and system-wide user authentication.
